# Fas 5.0 – Supportkontakt och kvarstående lanseringskrav

Officiell kontaktadress för Smoke Less: **contact@wolfyslayer.online**.

## Ingår i denna PR
- Synlig klickbar e-postadress på supportsidan.
- Samma kontaktadress på integritetssidan.
- Tydlig information om att kontakt via e-post inte automatiskt genomför kontoradering.
- Preview-APK förblir opublicerad.

## Återstår före offentlig lansering
- [ ] Bekräfta att adressen tar emot och besvarar meddelanden.
- [ ] Granska faktisk Firebase-/appdatahantering och färdigställ integritetspolicy.
- [ ] Verifiera fungerande kontoradering (i appen och/eller säker webbaserad begäran) och korrekt borttagning av serverdata.
- [ ] Bekräfta personuppgiftsansvarig, lagringstider, mottagare och användarrättigheter.
- [ ] Publicera och testa signerad Preview-APK och först därefter aktivera publiceringsmanifestet.
- [ ] Sluttesta mobil, tangentbord, skärmläsare och sidnavigering.

Detta är en kontaktuppdatering, inte ett påstående om att integritetspolicyn, raderingsprocessen eller APK-publiceringen är färdig.
